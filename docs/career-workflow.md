# 지원 작업공간 폐기

지원 전용 웹 화면·API와 `career` CLI는 제거됐다. 이 문서는 이전 참조를 위한 폐기 안내이며 지원 진행 절차를 제공하지 않는다.

경력 자료와 지원 관련 원문은 일반 [원문 조회](local-operations.md#native-원문-보존과-조회)·[기억 저장과 검색](local-operations.md#기억-저장과-다시-찾기) 경계에서 다룬다.

기존 진행 기록과 적용된 migration은 [기존 DB 보존 계약](local-operations.md#기존-db-업그레이드)을 따른다. 과거 진행 상태를 현재 제공되는 지원 기능으로 안내하지 않는다.
